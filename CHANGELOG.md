# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-15

### Added

- **AGENTS.md support**: `AGENTS.md` in the repository root is included in the prompt; commit conventions defined there take precedence (`commitGenerater.includeAgentsMd`)
- **Auto language detection**: New `auto` value for `commitGenerater.language` (now the default) that follows the language of recent commit history
- **Reasoning effort**: New `commitGenerater.reasoningEffort` setting and `Select Reasoning Effort` command
- **Status bar settings entry**: Bottom-right status bar item showing the current model / reasoning effort, opening a quick settings menu. It uses the same icon as the Source Control button, contributed as `$(commit-generater-icon)` via an icon font (`resources/commit-generater-icons.woff`, generated by `scripts/build_icon_font.py`)
- `Commit Generater: Settings` command

### Changed

- Model picker now loads models from `/models` while open and accepts any typed name as a custom model; falls back to manual entry if fetching fails
- Setup wizard reuses the new model picker and offers the `auto` language option
- All settings now use user-level configuration only; legacy workspace overrides are ignored and never modified
- Prompts now state the output language explicitly
- Chat requests no longer send `temperature` / `max_tokens`; provider defaults are used
- Default `commitGenerater.maxDiffLength` raised from 65536 to 131072 characters
- AGENTS.md and Git history read failures show a non-blocking warning and allow generation to continue, omitting unavailable guidelines or falling back to the VS Code display language

## [0.0.4] - 2026-02-05

### Added

- Breaking change indicator guidance in prompts (`feat!:` / `fix(scope)!:` or a `BREAKING CHANGE:` footer)

## [0.0.3] - 2026-01-19

### Changed

- Updated configuration descriptions to English
- Switched default commit message language to English (`commitGenerater.language`: `en`)

## [0.0.2] - 2026-01-19

### Changed

- **Improved prompt template**: Enhanced prompt with detailed Conventional Commits guidelines
  - Added comprehensive type descriptions (feat, fix, docs, style, refactor, perf, test, build, ci, chore, revert)
  - Added scope guidelines with common examples
  - Added description rules (imperative mood, 50 char limit)
  - Added body and footer guidelines
  - Improved diff formatting with code blocks

### Added

- **Lock file exclusion**: Automatically filter out lock files from diff analysis
  - Supports 60+ lock file patterns across multiple languages (JavaScript, Python, Rust, Go, Ruby, PHP, etc.)
  - Excludes common build directories (node_modules, dist, build, vendor, etc.)
  - Prevents large lock files from consuming context window

## [0.0.1] - 2026-01-18

### Added

- Initial release
- AI-powered commit message generation using OpenAI-compatible APIs
- Support for Conventional Commits format
- Multi-language support (English and Chinese)
- Setup wizard for first-time configuration
- Model selection from API provider
- Support for new repositories without commit history
